# Plan 10K

Plan de entrenamiento adaptativo hasta un 10K el 31 de diciembre de 2026. Página estática: los datos de cada persona se guardan solo en su navegador.

Incluye [Tesseract.js](https://github.com/naptha/tesseract.js) (Apache-2.0) y datos de idioma de tessdata para leer capturas en el propio dispositivo.
